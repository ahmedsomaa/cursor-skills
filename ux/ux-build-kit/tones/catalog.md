# Tones catalog

Pick from this list only (id · name · fit). After pick, open that tone’s HTML guide. Do **not** read `index.html` or every tone file for the pick.

- **`swiss`** — Swiss: Grid-led modernist clarity — objective, typographic, little ornament.
- **`minimalism`** — Minimalism: Zen reduction — one clear action, intentional empty space.
- **`maximalism`** — Maximalism: More is more — layered color, mixed type, dense visual rhythm.
- **`neo-brutalism`** — Neo-brutalism: Raw, loud, high-contrast — thick borders and hard shadows.
- **`soft`** — Soft: Friendly cushioned UI — rounded, airy, low-contrast comfort.
- **`editorial`** — Editorial: Magazine discipline — type-led hierarchy and long-form calm.
- **`liquid-glass`** — Liquid glass: Translucent layered panels — light, blur, and specular depth.
- **`dark-industrial`** — Dark industrial: Ops / infra night mode — dense, technical, status-first.
- **`bauhaus`** — Bauhaus: Primary geometry — circle, triangle, square as the visual system.
- **`calm-density`** — Calm density: Lots of information, still quiet — Linear/Notion-like composure.
- **`japandi`** — Japandi: Japanese calm × Scandinavian warmth — sparse, natural, precise.
- **`terminal`** — Terminal: CLI aesthetic — monospace, prompts, phosphor on black.
- **`clay`** — Clay: Claymorphism — soft extruded shapes, candy light, playful depth.
- **`aurora`** — Aurora: Mesh-gradient night sky — luminous color fields, soft glow UI.
- **`cyberpunk`** — Cyberpunk: Neon noir — rain-soaked tech, glitch accents, high-contrast night.
