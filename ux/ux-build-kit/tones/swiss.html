1Core Philosophy

Purpose, emotional boundaries, and when to use this aesthetic.

  • Structure is the beauty; alignment beats decoration.
  • One signal accent; neutrals do the rest.
  • Hierarchy from type scale and rules, not shadow theater.

Real products

GOV.UK Design System · Braun · The Guardian · International Typographic Style · IBM Plex

From our catalog

  • Closest systems: govuk, primer, atlassian
  • Also fits: IBM Carbon (restrained), Helvetica-era brand systems

2Layout & Spatial Architecture

Canvas organization: grids, alignment, density — not arbitrary placement.

  • Modular or asymmetric grid with visible columns/margins.
  • Hairline separators instead of soft card stacks.
  • Reading column or split content ‖ meta sidebar.

3Typography Rules

Typeface choices, weights, and scale limits that build hierarchy.

  • Neo-grotesk / grotesque sans throughout.
  • Strong modular type scale; asymmetric headlines OK.
  • Avoid display serif and playful rounded faces.

Suggested fonts

  • UI / bodyInter — neutral grotesque
  • UI altHelvetica Neue / Arial — system fallback stack
  • DisplayNeue Haas Grotesk — or Akzidenz-Grotesk

4Component Anatomy

Borders, corners, shapes, shadows, and icon language.

Border radius

square0 · Structural / technical corners.
  • Hairline 1px borders; no soft elevation.
  • Flush-left type blocks; sharp rectangular chrome.

Icon rules

  • Thin geometric stroke icons.
  • Optical square alignment to the grid.
  • No filled candy icons or skeuomorphic glyphs.

Icon libraries

  • PrimaryLucide — 24px stroke
  • AltPhosphor (thin/light) — geometric

5Intentional Color Systems

Limited spectrum; how colors interact for utility and emphasis.

  • Black / white / gray base.
  • One sharp signal (often red or brand primary).
  • No gradients; flat semantic status only when needed.

6Do vs Don’t Matrix

Side-by-side guardrails — keep the Do, reject the Don’t.

Do
Strict grid, grotesque sans, hairline rules, one signal color.
Don’t
Soft blobs, clay shapes, or multi-accent rainbows.
