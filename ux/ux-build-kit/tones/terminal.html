1Core Philosophy

Purpose, emotional boundaries, and when to use this aesthetic.

  • Text is the UI.
  • Prompt → command → output rhythm.
  • No ornamental chrome.

Real products

GitHub CLI · Vercel CLI · Warp · replit (console) · classic green-phosphor CRT UIs

From our catalog

  • Closest systems: primer, carbon, atlassian
  • Also fits: CLI tool docs themes, Hacker / devops dashboards

2Layout & Spatial Architecture

Canvas organization: grids, alignment, density — not arbitrary placement.

  • Full-bleed console panels.
  • ASCII / box-drawing structure.
  • Single column command streams.

3Typography Rules

Typeface choices, weights, and scale limits that build hierarchy.

  • Monospace only.
  • No proportional headlines in UI.
  • ASCII box drawing welcome.

Suggested fonts

  • UI / allJetBrains Mono — coding default
  • AltIBM Plex Mono — terminal
  • RetroIBM VGA / Perfect DOS VGA — nostalgia

4Component Anatomy

Borders, corners, shapes, shadows, and icon language.

Border radius

  • Block cursor / prompt glyphs.

Icon rules

  • No icons — use ASCII or omit.
  • Chevrons as > prompts.
  • Folder paths as navigation.

5Intentional Color Systems

Limited spectrum; how colors interact for utility and emphasis.

  • Black / near-black.
  • Phosphor green or amber.
  • Red only for errors.

6Do vs Don’t Matrix

Side-by-side guardrails — keep the Do, reject the Don’t.

Do
Mono only, prompt rhythm, phosphor contrast.
Don’t
Rounded marketing cards or icon-grid navigation.
