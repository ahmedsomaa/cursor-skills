# Design systems catalog

Pick from this list only (id · name · fit). After pick, open that system’s HTML guide. Do **not** read `index.html` or every system file for the pick.

- **`ant-design`** — Ant Design: Enterprise forms and dashboards driven by one seed color.
- **`astryx`** — Astryx (Meta): Meta’s open, themeable React design system for product and agent-ready SaaS UIs.
- **`atlassian`** — Atlassian Design System: Collaboration and work-management products.
- **`blueprint`** — Blueprint: Dense desktop-class data and ops interfaces in the browser.
- **`canvas`** — Canvas: Enterprise HR and finance SaaS — dense forms, records, and admin workflows.
- **`carbon`** — Carbon: Dense product UI for tools and data.
- **`chakra`** — Chakra UI: Composable React SaaS UI with accessible primitives and a themeable token model.
- **`cloudscape`** — Cloudscape (Amazon / AWS): Amazon / AWS console and cloud-admin SaaS — dense resources, wizards, and ops tables.
- **`eui`** — Elastic UI (EUI): Dense observability, search, and data-tool SaaS with strong table and chart patterns.
- **`evergreen`** — Evergreen: B2B SaaS consoles — practical React components with a calm enterprise feel.
- **`fluent-2`** — Fluent 2: Productivity apps that share a neutral, shared, and brand palette.
- **`forma-36`** — Forma 36: Content and editorial tools.
- **`garden`** — Garden: Support, messaging, and agent-workspace SaaS with calm, usable chrome.
- **`geist`** — Geist: Developer and AI-product SaaS — sharp, minimal, high-contrast product chrome.
- **`gestalt`** — Gestalt: Creation and content products in Pinterest's design language.
- **`govuk`** — GOV.UK Design System: Public services that need a small, tested, accessible set.
- **`helios`** — Helios: Infrastructure and platform SaaS — technical, structured, calm product UI.
- **`leafygreen`** — LeafyGreen: Developer-data and cloud console SaaS with approachable green brand accents.
- **`lightning`** — Lightning Design System: Record-heavy CRM and admin apps.
- **`mantine`** — Mantine: Full-featured React component library for dense SaaS dashboards and forms.
- **`material-3`** — Material 3: Cross-platform apps that generate color, type, and elevation from one source color.
- **`netflix`** — Netflix (public brand): Dark cinematic SaaS / media product language — red CTA, charcoal surfaces. Hawkins (internal) is not fully public.
- **`pajamas`** — Pajamas: Developer-tool and DevOps SaaS — content-heavy product UI with clear hierarchy.
- **`paste`** — Paste: Messaging, account, and support products built from a theme of tokens.
- **`polaris`** — Polaris: Commerce admin, checkout, and point of sale.
- **`primer`** — Primer: Developer tools and content-heavy product UI.
- **`shadcn`** — shadcn/ui: Copy-paste Radix + Tailwind components for modern product and AI SaaS UIs.
- **`spark`** — Spark UI (Netlify): Netlify product and marketing foundations — tokens, components, and light/dark theming for web SaaS.
- **`spectrum`** — Spectrum: Creative tools with separate mobile and desktop scales.
- **`stripe`** — Stripe Apps UI: Stripe Dashboard–aligned SaaS chrome — calm finance UI, purple action, dense tables and drawers.
- **`uber-base`** — Base: One foundation shared across many Uber products.
- **`uswds`** — U.S. Web Design System: Public-sector services and accessible government SaaS-style portals.
- **`vibe`** — Vibe: Work-management and board-based SaaS with colorful, friendly product UI.
