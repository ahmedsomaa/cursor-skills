# Shape

## Produce

Radius and border width from product character (sharp / slight / round).

- Short radius ramp; tiny border-width set; roles in `system.json` `shape`.

## Represent

`shape.html`:

1. What / Why / When
2. Radius scale specimens
3. Controls and surfaces using default radii
4. Border widths
5. Token table + Do / Don't

## Do / Don't

**Do:** Consistent corners across controls and cards.

**Don't:** A unique radius per component unless a principle demands it.
