# Content

## Produce

A content system: vocabulary, labels, errors, formatting — not “be friendly.”

- Preferred terms table; action-oriented buttons; actionable errors; date/time/currency formats; capitalization.
- Arabic/English conventions when the product needs both.
- Same concept → same name everywhere. `system.json` `content` holds vocabulary + key rules.

## Represent

`content.html`:

1. What / Why / When
2. Voice in examples (not adjectives alone)
3. Terminology table (Preferred · Avoid)
4. Button / link label rules with ✓ / ✗
5. Before/after errors and empty states
6. Formatting examples
7. Do / Don't

## Do / Don't

**Do:** Product vocabulary; consistent terms; actionable errors; realistic examples; bilingual rules when needed.

**Don't:** Vague tone rules; synonym hopping; technical errors for users; placeholder lorem; invent terms per screen.
