Docs chrome · Typography options

Agent guide for documentation site font pairings. Pick one after the layout template. Write heading / body / mono into docs.json fonts. Custom is always last (user names Google Fonts). For geist-geist-mono, if Geist cannot load, use Inter + JetBrains Mono.
