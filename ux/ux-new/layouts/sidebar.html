Sidebar Layout

Agent guide for the Sidebar docs chrome. The Details block is not copied into design/ — implement from the wireframes. Examples: Mintlify, Fumadocs.

1. Details

Name
Sidebar Layout
Examples
Mintlify · Fumadocs — sidebar + reading column docs chrome
Style
Docs chrome corners (docs.json style). Wireframes: style.html — square · squircle · pill. Apply to nav buttons, chips, cards, and the theme control.
Fonts
This agent-guide HTML uses Inter for wireframe readability. Product docs pick from typography.html (best three for Sidebar):
  • Inter + JetBrains Mono — default, neutral docs
  • Source Sans 3 + Source Code Pro — long-form sidebar reading
  • Literata + IBM Plex Mono — long-read sidebar documentation
Icons
Use Lucide Icons
Description
Left sidebar + narrow reading column. Header: system name and “Design handbook” (left), theme toggle (right), then a separator. Three uppercase groups — BRIEF, DESIGN SYSTEM, SCREENS. Design system lists category buttons only; subcategories open from the category page. Screens nest features with Storyboard and Designs under each. Brief · Overview is a one-scroll spec sheet. Each Design system category has separator + wireframes (Foundations specimens; Components/Patterns category+specimen; Content; Accessibility). Screens last.
