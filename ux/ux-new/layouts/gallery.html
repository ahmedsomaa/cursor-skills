Gallery Layout

Agent guide for the Gallery docs chrome. Details are not copied into design/ — implement from the wireframes. Example: Mantine UI (card/tile gallery for subsections). No navbar — home uses three page sections (Brief, Design system, Screens); cards open subsections.

1. Details

Name
Gallery Layout
Examples
Mantine UI — card/tile gallery for subsections (not a docs navbar)
Style
Docs chrome corners (docs.json style). Wireframes: style.html — square · squircle · pill. Apply to cards and the theme control.
Fonts
This agent-guide HTML uses Inter. Product docs: typography.html (pairings that list gallery).
Icons
Use Lucide Icons
Description
No navbar / main-nav strip. Header is one row, two columns: long column = system title + “Design handbook” subtitle; small column = theme toggle. Home (index.html) stacks three page sections — Brief, Design system, Screens — each with a section heading and a card grid for its subsections. Cards open nested pages (still no navbar; optional crumb + page title). Design system cards → Foundations subcategory cards → section specimen. Screens cards → feature → Storyboard / Designs cards → screen + states.
Wireframes
Home · Brief · Foundations · Components · Patterns · Content · Accessibility · Screens
