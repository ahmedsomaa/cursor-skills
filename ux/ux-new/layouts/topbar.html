Topbar Layout

Agent guide for the Topbar docs chrome. Details are not copied into design/ — implement from the wireframes. Example: Chakra UI docs — top navbar for main areas; horizontal tabs for Design system categories; vertical tabs for Foundations (and other) subsections.

1. Details

Name
Topbar Layout
Examples
Chakra UI — horizontal docs bar + subcategory tabs (stacked page underneath)
Style
Docs chrome corners (docs.json style). Wireframes: style.html — square · squircle · pill. Apply to nav items; tab underline stays 2px solid.
Fonts
This agent-guide HTML uses Inter. Product docs: typography.html (pairings that list topbar).
Icons
Use Lucide Icons
Description
Navbar: name + “Design handbook” (left), centered Brief / Design system / features, theme (right). Horizontal tabs under the bar for the current main’s top-level children (Design system → Foundations · Components · Patterns · Content · Accessibility; Feature → Storyboard · Designs; Brief → Overview). Vertical tabs (left column) for the open category’s subsections — Foundations → Principles · Color · Typography · …; Components → Button · Input · …; Patterns → pattern names; Designs → screen names. Right column = page title + specimen. Horizontal tabs stay on Design system categories; do not replace them with Foundations items.
Wireframes
Brief · Foundations · Components · Patterns · Content · Accessibility · Screens
