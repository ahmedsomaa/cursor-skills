Topbar Layout

Agent guide for the Topbar docs chrome. Details are not copied into design/. Build from topbar.jobs.md (staged reads); open a single #wf-* here only if needed. Wireframes = IA/placement only — ship a finished unique handbook. Example: Chakra UI docs — top navbar for main areas; horizontal tabs for Design system categories; vertical tabs for Foundations (and other) subsections.

1. Details

Name
Topbar Layout
Examples
Chakra UI — horizontal docs bar + subcategory tabs (stacked page underneath)
Style
Docs chrome corners (docs.json style). Wireframes: style.html — square · squircle · pill. Apply to nav items; tab underline stays 2px solid.
Fonts
This agent-guide HTML uses Inter. Product docs: typography.html (pairings that list topbar). Docs fonts = handbook default (incl. principles / patterns / icons / themes prose). Design-system typography only inside UI samples, typography specimens, storyboards, and screens.
Icons
None in docs chrome — text labels only. Product Foundations / screens may use Lucide; never mix icon-nav with text-only nav.
Description
Navbar: name + “Design handbook” (left), centered Brief / Design system / features, theme (right). Horizontal tabs under the bar for the current main’s top-level children (Design system → Foundations · Components · Patterns · Content · Accessibility; Feature → Storyboard · Designs; Brief → Overview). Vertical tabs (left column) for the open category’s subsections — Foundations → Principles · Color · Typography · …; Components → Button · Input · …; Patterns → pattern names; Designs → screen names. Right column = page title + specimen. Horizontal tabs stay on Design system categories; do not replace them with Foundations items.
Wireframes
Brief · Foundations (Principles · Color · Typography · Spacing · Layout · Shape · Elevation · Icons · Motion · Logo · Themes) · Components · Patterns · Content · Accessibility · Screens
