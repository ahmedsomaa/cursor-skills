Topbar Layout

Agent guide for the Topbar audit docs chrome. Details are not copied into design/audit/. Build from topbar.jobs.md (staged reads); open a single #wf-* only if needed. Wireframes = IA/placement only — ship a finished audit docs site. Example: Chakra UI docs — top navbar for the five audit steps; horizontal tabs for flows / opportunity children; vertical tabs for screens inside a redesign package.

1. Details

Name
Topbar Layout
Fit
Horizontal browsing across audit steps with tabbed flows and redesign packages.
Examples
Chakra UI — horizontal docs bar + subcategory tabs
Style
Docs chrome corners (audit/docs.json style). Wireframes: style.html — square · squircle · pill. Apply to nav items; tab underline stays 2px solid.
Fonts
This agent-guide HTML uses Inter. Audit docs: typography.html (pairings that list topbar).
Icons
None in docs chrome — text labels only. Product Foundations / screens may use Lucide; never mix icon-nav with text-only nav.
Description
Navbar: name + “Audit handbook” (left), centered Understand / Walkthrough / Evaluate / Prioritize / Redesign, theme (right). Horizontal tabs under the bar for the current main’s children (Walkthrough → flow ids; Redesign → opportunity ids; Understand/Evaluate/Prioritize → Overview / Findings / Backlog). Vertical tabs when a redesign opportunity is open — screen names; right panel = specimen.
Wireframes
Understand · Walkthrough · Evaluate · Prioritize · Redesign
