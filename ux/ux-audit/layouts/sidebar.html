Sidebar Layout

Agent guide for the Sidebar audit docs chrome. The Details block is not copied into design/audit/. Build from sidebar.jobs.md (staged reads); open a single #wf-* only if needed. Wireframes = IA/placement only — ship a finished audit docs site. Examples: Mintlify, Fumadocs.

1. Details

Name
Sidebar Layout
Fit
Written audit reports — Understand, Evaluate, Prioritize with long reading columns.
Examples
Mintlify · Fumadocs — sidebar + reading column docs chrome
Style
Docs chrome corners (audit/docs.json style). Wireframes: style.html — square · squircle · pill.
Fonts
This agent-guide HTML uses Inter. Audit docs pick from typography.html (pairings that list sidebar).
Icons
None in docs chrome — text labels only. Product Foundations / screens may use Lucide; never mix icon-nav with text-only nav.
Description
Left sidebar + reading column. Header: product name and “Audit handbook” (left), theme toggle (right). Five uppercase groups — UNDERSTAND, WALKTHROUGH, EVALUATE, PRIORITIZE, REDESIGN. Walkthrough nests flow buttons. Redesign nests opportunity ids (each package: before → problem → after index + screen pages).
Wireframes
Understand · Walkthrough · Evaluate · Prioritize · Redesign
