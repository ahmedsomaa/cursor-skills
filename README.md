# cursor-skills

Skills I use with Cursor agents.

## Building the product

Product work is spec-driven. I use [Matt Pocock's skills](https://github.com/mattpocock/skills) for that: grill an idea until it is sharp, turn it into a spec, split the spec into tickets, and implement with tests. The code is built from a written spec, not from a chat that drifted.

## Designing the product

How the product looks and behaves is a separate set, in [UX](UX/README.md). I made those skills because I design in HTML, not in Figma. They produce a design system and high-fidelity screens a developer can read and later implement.
