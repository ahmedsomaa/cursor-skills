# Elevation

## Produce

Small stack: rest, raised, overlay (sunken only if real). Light and dark values both feel like this product. Shadow or tonal layers — pick one model. Write into `system.json` `elevation`.

## Represent

`elevation.html`:

1. What / Why / When
2. Role cards on canvas in light and dark
3. Relative stack + UI fragments (menu, modal, sticky)
4. Token table + Do / Don't

## Do / Don't

**Do:** Theme-aware depth; show stacking order.

**Don't:** Naive invert of light shadows for dark; one-off shadows in components.
