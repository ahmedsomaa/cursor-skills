# Layout & grid

## Produce

Follow the brief: mobile first, website first, or both.

- Max width, content width, gutters, breakpoints, repeated regions (shell, main, aside).
- Short breakpoint set. Put rules in `system.json` `layout`.

## Represent

`layout.html`:

1. What / Why / When + viewport stance
2. Width frames and breakpoint labels
3. Grid / region wire
4. Phone and desktop skeletons (both when brief says both)
5. Do / Don't

## Do / Don't

**Do:** Match the brief’s primary viewport; show structures, not full screens.

**Don't:** Assume desktop patterns work on mobile; invent breakpoints the product never uses.
