# Spacing

## Produce

One shared scale (about 6–10 steps), usually 4px-based.

- Cover inset, gap, and section separation. Page gutters live here or on layout — one home only.
- Density matches principles. Name steps (`space-1`… or `xs`…`xl`) with values in `system.json` `spacing`.

## Represent

`spacing.html`:

1. What / Why / When
2. Scale as labeled bars (name · value)
3. Inset / stack / row / section specimens
4. Token table + Do / Don't

## Do / Don't

**Do:** Small intentional ramp; show gaps visually; same scale everywhere.

**Don't:** Ad-hoc pixels outside the scale; a token for one screen’s odd gap.
