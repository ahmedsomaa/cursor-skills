# Themes

## Produce

Prove light and dark share role names and both feel like this product. Values come from color and elevation. `system.json` `themes` states the rule (e.g. same roles; swap with `data-theme`). Page theme control switches docs chrome and product frames; persist in `localStorage`.

## Represent

`themes.html`:

1. What / Why / When
2. Same UI fragment in light and dark (side by side on fixed surfaces)
3. Stress cases: muted text, borders, status, overlay
4. Do / Don't

## Do / Don't

**Do:** Product-specific dark; shared role names; paired comparison.

**Don't:** Generic invert; theme-only hacks inside components.
